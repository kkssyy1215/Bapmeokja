## 3. 실행 방법

```bash
docker compose up -d --build
```

```bash
npm run test:e2e
```

결과는 터미널과 `playwright-report/`에 나옵니다(`npm run test:e2e:report`). 요약 JSON은 [`results/e2e-result.json`](results/e2e-result.json)에 있습니다. 실패하면 `test-results/`에 화면과 동작 기록이 남습니다. GitHub Actions의 `e2e` 작업이 PR마다 같은 테스트를 실행합니다.

실행하면 웹을 운영 모드로 빌드합니다. 개발 서버는 `.env.local`의 목업 설정을 다시 읽어 시연 데이터로 통과할 수 있어(ISSUE-007), 쓰지 않습니다. 목업 모드로 뜨면 로그인 단계에서 실패하게 해 두었습니다.

## 4. 한계

- 배포 주소가 아니라 로컬 서버에서 실행했습니다. 배포본에는 같은 코드가 들어간 것만 확인했습니다.
- 레시피 상세와 장보기 목록, 댓글 삭제, 알림 설정 화면은 아직 다루지 않습니다.
- Chrome 웹만 확인합니다. iOS·Android 앱은 대상이 아닙니다.
- 오류 안내 창이 실제로 보이는지는 별도 테스트가 없습니다.
- 사진 분석은 분석 결과가 나오고 저장되는지만 확인합니다. 정확도는 측정하지 않습니다. 키가 없는 CI에서는 시연용 분석기로 실행됩니다.
- 프론트 Jest 단위 테스트는 아직 없습니다.
